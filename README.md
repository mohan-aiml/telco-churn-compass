# 📊 Telco Churn Compass – Customer Churn Analytics

## 📌 Project Overview

Telco Churn Compass is a Customer Churn Analytics project designed to analyze customer behavior, identify churn patterns, and understand the key factors influencing customer retention.

The project combines Python-based data analysis with an interactive dashboard to transform raw customer data into meaningful business insights that support data-driven decision-making.

## 🎯 Project Objectives

- Analyze customer churn patterns and trends.
- Identify customer segments with high churn rates.
- Understand factors influencing customer churn.
- Analyze customer demographics, contracts, tenure, and payment methods.
- Develop customer retention strategies.
- Present analytical findings through an interactive dashboard.
